## How it works

`main.ts` (Node 22, standard library only) writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validates the gate (1–120 characters, a single non-blank line), then reads the file back and verifies its sha256 before printing the result. The output is deterministic: every run writes the same bytes.
